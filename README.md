# 基于目标检测的山火的早期烟雾检测以及起火点检测系统
山火是一种极具危险性的自然灾害，在许多地区都会造成严重的生命财产损失。由于山火火势蔓延迅速，往往难以及时发现和控制。我们团队经过大量的查找信息，结合团队成员互相之间的意见和方法，开发了一套高效准确的检测和预防系统来加强山火监测和预警工作。 待开发系统名称:Yolov5山火的早期烟雾检测以及起火点检测系统
